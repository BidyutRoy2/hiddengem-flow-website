Features

Everything a script manager should do — and nothing it shouldn't.

One extension, one dashboard. Scripts run where you allow them, update only when you allow it, and stay out of your way the rest of the time.

Daily Tasks

Save the sites you open every day by name and URL, then open one, several, or all of them with Open All. Pin, search, export and import — with honest reporting of exactly what opened.

Script manager

Install, edit, enable or remove userscripts from one dashboard. Every script is scanned before install — you confirm exactly what will run.

Built-in script store

Browse the official script store from this site or inside the extension. Copy a script's URL, paste it in the dashboard, done — no files to manage.

Floating panel

A small on-page panel shows which scripts are active on the current tab, with run status and quick toggles — no need to open the dashboard.

Update checker

Flow checks GitHub Releases and your installed scripts for newer versions, and shows a banner only when there is actually something to update.

Private by design

No accounts, no analytics, no trackers. Scripts and settings stay in your browser — the only calls out are the store index and script URLs you ask for, the automatic update check, and favicon images next to task sites.

Backup & restore

Export all your scripts and settings to a single file, and restore them on a new machine or a fresh browser profile in seconds — no account, no cloud, your file stays yours.

Notepad

Quick local notes in the floating window and the Dashboard — the same notes in both. Markdown, checklists, due dates, tags and pins. Notes live in this browser only.

Flows & reminders

A Flow runs a whole routine — tasks, scripts and a note — in one click or on a schedule. Task reminders open their sites at the time you set.

Full Details

Every feature, in detail.

The complete release, feature by feature — how each one actually works, including the limits. Nothing here needs an account, and nothing runs until you say so.

The floating window

  • Click the toolbar icon on any website and a small window opens. Drag it by the header, minimize it, close it — its position is remembered between visits.
  • It lives in a Shadow DOM, so the site's own styles can't break it — and it can't break the site.
  • Works with no website open: on a new tab, chrome:// or about:blank, the same UI opens as a standalone popup window (360×680). Clicking again focuses it instead of opening a duplicate.
  • Edit layout — drag to reorder the window's pages, tap the eye to hide or show a page, tap the star to pick the page that opens first. Applies to the floating window, Side Panel and Popup; the Dashboard always shows all tabs.

Daily Tasks, in detail

  • Save sites by name + URL. Pin, edit, delete, search — duplicate URLs are rejected.
  • Open All opens tabs one by one (~350 ms apart, max 50 at a time). Only the first tab opens in the foreground; the result is reported honestly — “Opened 3 tabs.” — never silently dropped.
  • Open-tabs tracking: a task whose site is already open shows a green ● Open badge (×N when several) and a Close button that closes exactly those tabs. Clicking the badge focuses the tab.
  • Export tasks (.json) downloads everything to one file; Import merges a backup back — already-saved URLs are skipped, nothing is ever deleted, and one line reports the counts. A file that isn't a tasks backup is refused with a clear error.
  • Smart Open All skips sites that are already open, and snooze takes a task out of Open All for a while.

Script Manager, in detail

  • Every install is scanned first — score 0–100, grade A–F — and needs your explicit Confirm. The scan warns; it never blocks.
  • Version history keeps the last 10 versions of each script, with a one-click Rollback.
  • Import from .js, .user.js, .txt or any text file, pasted code, or a URL you fetch yourself. Export any script as .user.js or .txt.
  • Built-in editor, plus folders, tags, bulk actions and an archive for scripts you don't use. Install straight from a URL — after the same scan + confirm.
  • A script with no @match patterns is saved but never registered — Flow tells you so, plainly.

Script Store & the bridge

  • The official store lives in the public hiddengem-flow-store repo, fetched via raw.githubusercontent first, jsDelivr as fallback — and only when you click Load store. Nothing is fetched before that.
  • Search, and sort by Recently updated / Latest / Name. Installing always goes through scan + your confirm — nothing installs itself.
  • Smart Notification Bridge: if the site you're on already has an official script, a dismissible banner says so and offers it in one click from the store.
  • A script you installed stays yours even if it is later removed from the store.

Notepad, in detail

  • The same notes in the floating window and in the Dashboard. Search as you type.
  • Notes support Markdown, checklists and due dates. Brand each note (HiddenGem / Personal / Work), add up to 10 tags, pin to the top, and copy the note body in one click.
  • Delete needs a two-step confirm. An empty title falls back to the note's first line, or “Untitled note”.
  • Notes live in this browser only — no server, no sync.

Flows, reminders & schedules

  • A Flow runs a routine — tasks + scripts + a note — in one click, or on a schedule.
  • Task reminders open their sites at the time you set; Open All can also run on a schedule.
  • Scheduled scripts are per-script opt-in and keep their own run log, so you can see exactly what ran and when.
  • Omnibox: type flow + a task name in the address bar to open that task.

Runs & logs

  • Multi-tab Logs: every tab the extension opens gets a run entry — Queued → Running → Done — with the scripts that match it.
  • Stop All closes only the tabs this extension opened — never your other tabs.

Window modes, menus & shortcuts

  • Three window modes — Floating window, native Side Panel, or a standalone Popup window. Switch from the toolbar icon, Alt+Shift+F, the Dashboard, or each surface's Switch menu. Default is Floating.
  • Right-click menu: save a site to Daily Tasks, save a selection as a note, or run a script on the page.
  • Alt+Shift+F toggle the window · Alt+Shift+T add the current site as a task · Alt+Shift+D open the Dashboard · Alt+Shift+N quick note.

More tools built in

  • Sessions — save a set of open tabs and reopen them later.
  • Userstyles — your own per-site custom CSS.
  • Scratchpad for throwaway code, a per-site dossier, store collections, and a per-script storage viewer that shows what a script stored.

Backup, sync & updates

  • Automatic backup keeps the last 3 snapshots. Restore from a snapshot, or export / import a backup file. Backups never contain tokens or API keys.
  • Optional sync to your own WebDAV / Gist / Drive — off by default; you opt in, and it's your storage, not ours.
  • Updates are noticed, not installed: unpacked extensions can't update themselves, so Flow checks GitHub Releases at most once every 6 hours (plus a manual Check for updates in Settings). When a newer build exists, the Overview tab shows a banner with the release tag and the manual steps — replace the files, press Reload. Never press Remove: that deletes your tasks and scripts.

What scripts can use — the GM API

  • Six GM functions exist: GM_setValue, GM_getValue, GM_notification, GM_addStyle, GM_xmlhttpRequest (only with @grant GM_xmlhttpRequest and the host in @connect) and GM_setClipboard — plus the GM.* object form.
  • GM_openInTab, GM_download, unsafeWindow and the rest are not implemented — a script that calls one gets a scanner warning and a runtime error, never a fake.
  • GM_setValue / GM_getValue values live in the page origin's localStorage, namespaced per script — visible to the page's own JavaScript. Never store secrets with GM_*.
  • The scanner is a regex heuristic: it strips comments and strings first, so it can miss obfuscated code and can flag a pattern used safely. It is a warning, never proof of safety.
  • Only JavaScript userscripts run in a page. A file in another language can be opened and inspected, but it cannot run — the import says so plainly.

Privacy, precisely

  • Everything you save — tasks, scripts, positions, logs — stays in chrome.storage.local on your machine. No account, no analytics, no telemetry.
  • Only two automatic external requests exist: a favicon image next to each task site (Google's s2 service; a letter tile shows instead if it fails), and the update check asking api.github.com for the latest public release.
  • The store is fetched only when you click Load store. Importing from a URL fetches only that URL, when you click it.

Permissions — every one, and why

Flow asks for no host permissions at all. Site access for userscripts is an optional permission (*://*/*), granted per site only when you ask a script to run. Here is the complete list from the manifest:

storage

Save tasks, scripts, window position and logs — all locally.

tabs

Open the dashboard and task sites; read the active tab for “Add current site”.

scripting

Inject the floating window into the tab when you click.

activeTab

Temporary access to the tab you clicked — this is what lets Flow ask for no host permissions at all.

userScripts

Register and unregister your userscripts. Chrome additionally needs the Allow User Scripts toggle (see the install guide).

notifications

Only for GM_notification calls from a running userscript.

sidePanel

Open the native Side Panel window mode.

contextMenus

Right-click: save a site, save a selection as a note, run a script on the page.

alarms

Reminders, scheduled Open All, and scheduled scripts.

Optional permission: tabGroups — groups the tabs Open All opens; granted only if you enable tab grouping. There is no default popup, and no required host permission.

FAQ

        
Straight answers

      

      

        

          Why isn't Flow on the Chrome Web Store? 
          
For now, Flow is distributed through GitHub Releases and installed with Load unpacked. That keeps every release open for inspection — the zip you download is exactly the code that runs. A Web Store listing may come later; the install guide above covers the manual route in about two minutes.

        

        

          Can this website install a script for me? 
          
No — and no website can. Chrome removed website-triggered extension installs in 2018, and web pages can't open extension pages. That's why the store uses Copy install URL: you paste the link into the dashboard, review the scan, and confirm yourself. It's one extra step, and it's the safe one.

        

        

          Is my data collected anywhere? 
          
No. Flow has no analytics, no accounts and no server of its own. Scripts and settings live in your browser's local storage. The only network calls are fetching a script URL or the store index when you ask for it, the automatic update check (at most once every 6 hours), and favicon images next to task sites.

        

        

          How do updates work? 
          
Unpacked extensions can't update themselves — Chrome gives them no way to replace their own files. So Flow notices instead: it checks GitHub Releases at most once every 6 hours, and the Dashboard's Overview tab shows a banner with the new version and the manual steps (download, replace the files in the same folder, press Reload on the extensions page). Never press Remove — that deletes your saved tasks and scripts. One honest quirk: a fresh install of a just-uploaded build may briefly report an update pointing at itself; Dismiss hides it until the next build.

        

        

          Which scripts can Flow run? 
          
JavaScript userscripts with @match patterns. Six GM functions are supported — GM_setValue, GM_getValue, GM_notification, GM_addStyle, GM_xmlhttpRequest (with @grant and @connect) and GM_setClipboard, plus the GM.* object form. Functions like GM_openInTab, GM_download and unsafeWindow are not implemented: a script that calls one gets a scanner warning and a runtime error, never a fake. The full breakdown is in the Full Details section above.

        

        

          How do I report a bug or suggest a script? 
          
Open an issue on GitHub, or follow the HiddenGem channel on Telegram (@hiddengemnews) for release announcements and script drops.
